# betonwerk-social

This repository holds only images and videos that have been approved for posting on Instagram **@betonwerk.world**.
They are public so that the scheduling tool can fetch them by direct link.

- One folder per post under `posts/` (`YYYY-MM-<name>`), the slides numbered in posting order.
- Videos (Reels) under `videos/` (`YYYY-MM-<series>/<figure>-stare.mp4`), each approved before it arrives.
- Plain files only: no Git LFS, no source files, no game assets, nothing else from the game repository.
- An image arrives here only after it has been approved for posting.

## Signup page

`index.html` and `privacy.html` at the root are the bio-link page (GitHub Pages, main / root): the BETONWERK cube, "SOON" and a launch-news email signup that posts to a Brevo form with double opt-in. Approved by Lion 28 Nov 2026.
