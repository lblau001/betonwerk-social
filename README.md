# betonwerk-social

This repository holds only images that have been approved for posting on Instagram **@betonwerk.world**.
They are public so that the scheduling tool can fetch them by direct link.

- One folder per post under `posts/` (`YYYY-MM-<name>`), the slides numbered in posting order.
- Plain files only: no Git LFS, no source files, no game assets, nothing else from the game repository.
- An image arrives here only after it has been approved for posting.
